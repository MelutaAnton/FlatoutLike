Цель шага по game-design цитата из Implementation Order, 
например «ездить по пустой сцене».

Регламент тот же, что и на предыдущих шагах
1. Сначала план файлов, жди ок.
2. code-writer для нового кода, code-reviewer параллельно.
3. EDITOR_SCRIPT_NEEDED помечай и делегируй editor-script-creator.
4. Не лезь в последующие шаги.
5. После завершения — жди моей проверки.

Дополнительные ограничения для этого шага
- если есть что-то специфичное, например «для машин используй 
  prefab Car_01 из AssetsThirdParty1Poly_DestructibleCars, 
  не создавай свой меш»
- или «для damage visual использовать стратегию A (material 
  swap) из §4 game-design — пустые поля для damagedMesh 
  и blendShapeWeights»
